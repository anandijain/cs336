# CS336 study

Personal Rust-first exercises for learning neural networks and preparing to work through Stanford CS336.

This repository contains successive from-scratch implementations rather than polished libraries:

- `micrograd`, `micrograd2`, and `micrograd3`: scalar automatic differentiation and small neural networks
- `micrograd_py`: a small Python reference implementation
- `makemore` and `makemore2`: character-level language-model exercises

The work is inspired by Andrej Karpathy's [micrograd](https://github.com/karpathy/micrograd) and [makemore](https://github.com/karpathy/makemore), and is not an official CS336 solution repository.
